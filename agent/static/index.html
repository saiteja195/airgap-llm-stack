What is this?

This console shows an LLM assistant that was installed into a locked-down Kubernetes cluster with no internet access. It searches your documents and uses a small language model running in the same cluster to answer, so no data leaves your network.

1 Readiness checks the setup, 2 Isolation proves the cluster really is offline, and 3 Ask lets you try it.

Air-gap
A network with no connection to the public internet.
Preflight / readiness check
Tests that run before and after install to find what the environment is missing.
NetworkPolicy
A Kubernetes rule that limits which pods can talk to which. Here the default is "deny everything", with a few explicit exceptions.
Token
A word fragment the model reads and writes. Answer speed is measured in tokens per second.
Sources / citations
The document passages the answer was based on, so you can verify it.
Safety check (query gate)
Optional step that refuses off-topic questions and prompt-injection attempts before the model runs.
